# Tetris — Core Gameplay

Core Tetris gameplay implemented in **Unity 6** (6000.0.32f1) with C#.

## Features
- Game board with line clearing (`Board`)
- All seven tetrominoes and their data (`Tetronimo`, `Data`)
- Piece movement, rotation with wall kicks, soft and hard drop (`Piece`)
- Ghost piece showing the landing position (`Ghost`)

## How to run
1. Clone the repository.
2. Open the folder in Unity Hub with Unity 6000.0.32f1 or newer.
3. Open `Assets/Scenes/SampleScene` and press Play.

## Controls
A, D — move · Q, E — rotate · S — soft drop · Space — hard drop
